Generates custom locale data for ICU4X based on CLDR and other data sources.

Also see the Rust API: https://docs.rs/icu_provider_export/2.3.0

Usage: icu4x-datagen [OPTIONS] --format <FORMAT>

Options:
  -v, --verbose
          Requests verbose output

      --format <FORMAT>
          Select the output format: a directory tree of files (fs), a single blob (blob), or a Rust module (baked).
          
          [possible values: fs, blob, baked]

  -W, --overwrite
          Delete the output before writing data.

  -s, --syntax <SYNTAX>
          --format=fs only: serde serialization format.
          
          [default: json]
          [possible values: json, bincode, postcard]

  -p, --pretty
          --format=baked, --format=fs only: pretty-print the Rust or JSON output files.

  -t, --cldr-tag <TAG>
          Download CLDR JSON data from this GitHub tag (https://github.com/unicode-org/cldr-json/tags)
          Use 'latest' for the latest version verified to work with this version of the binary.
          Ignored if '--cldr-root' is present. Requires binary to be built with `networking` Cargo feature (enabled by default).
          Note that some markers do not support versions before 41.0.0.
          
          [default: latest]

      --cldr-root <PATH>
          Path to a local cldr-{version}-json-full.zip directory (see https://github.com/unicode-org/cldr-json/releases).
          Note that some markers do not support versions before 41.0.0.

      --icuexport-tag <TAG>
          Download ICU data from this GitHub tag (https://github.com/unicode-org/icu/tags)
          Use 'latest' for the latest version verified to work with this version of the binary.
          Ignored if '--icuexport-root' is present. Requires binary to be built with `networking` Cargo feature (enabled by default).
          Note that some markers do not support versions before release-71-1.
          
          [default: latest]

      --icuexport-root <PATH>
          Path to a local icuexport directory (see https://github.com/unicode-org/icu/releases).
          Note that some markers do not support versions before release-71-1.

      --unicode-tag <TAG>
          Download versioned RSCD from unicode.org (`https://www.unicode.org/Public/{tag}/`). Use 'latest' for the latest version verified to work with this version of the binary, and 'latest-tag' for the literal tag 'latest' on unicode.org. Ignored if '--unicode-rscd-root' is present. Requires binary to be built with `networking` Cargo feature (enabled by default).
          
          [default: latest]

      --unihan-root <PATH>
          [DEPRECATED] Ignored

      --unicode-rscd-root <PATH>
          Path to a local Unicode RSCD root directory (see https://www.unicode.org/reports/tr44/tr44-37.html#Directory_Structure).

      --segmenter-lstm-tag <TAG>
          Download segmentation LSTM models from this GitHub tag (https://github.com/unicode-org/lstm_word_segmentation/tags)
          Use 'latest' for the latest version verified to work with this version of the binary.
          Ignored if '--segmenter-lstm-root' is present. Requires binary to be built with `networking` Cargo feature (enabled by default).
          
          [default: latest]

      --segmenter-lstm-root <PATH>
          Path to a local segmentation LSTM directory (see https://github.com/unicode-org/lstm_word_segmentation/releases).

      --tzdb-tag <TAG>
          Download tzdb from this IANA tag (https://data.iana.org/time-zones/releases/)
          Use 'latest' for the latest version verified to work with this version of the binary.
          Ignored if '--tzdb-root' is present. Requires binary to be built with `networking` Cargo feature (enabled by default).
          
          [default: latest]

      --tzdb-root <PATH>
          Path to a local tzdb directory (see any zip file from https://data.iana.org/time-zones/releases/, directory structure matching https://data.iana.org/time-zones/tzdb-2025a/).

      --trie-type <TRIE_TYPE>
          Whether to optimize CodePointTrie data structures for size ("small") or speed ("fast").
          Using "fast" mode increases performance of CJK text processing and segmentation. For more
          information, see the TrieType enum. The tries for the core (UAX #15 but not UAX #46)
          normalization forms use the fast trie type regardless of this setting.
          
          [default: small]
          [possible values: small, fast]

      --collation-root-han <COLLATION_ROOT_HAN>
          Which collation han database to use.
          
          [default: implicit]
          [possible values: unihan, implicit]

      --alt-variant <ALT_VARIANTS>...
          Which alt variants to enable.
          
          [possible values: datetime-ascii]

      --include-collations <INCLUDE_COLLATIONS>...
          Which less-common collation tables to include. 'search-all' includes all search tables.
          
          [possible values: search, searchji, search-all]

  -m, --markers <MARKERS>...
          Include these data markers in the output. Accepts multiple arguments.
          Set to 'all' for all markers, or 'none' for no markers.

      --markers-for-bin <BINARY>
          Analyzes the binary and only includes markers that are used by the binary.

      --attribute-filter <FILTER>
          Filter attributes on markers for a domain. Accepts form `domain=/regex/`.

  -l, --locales [<LOCALES>...]
          Include this locale in the output. Accepts multiple arguments. Set to 'full' or 'modern' for the respective CLDR locale sets, 'none' for no locales, or 'recommended' for the recommended set of locales.
          
          [default: recommended]

  -o, --out <PATH>
          Path to output directory or file. Must be empty or non-existent, unless --overwrite is present, in which case the directory is deleted first. For --format=blob, omit this option to dump to stdout. For --format={dir,mod} defaults to 'icu4x_data'.

      --use-separate-crates
          --format=baked only: use types from individual `icu_*` crates instead of the `icu` meta-crate.

      --no-internal-fallback
          --format=baked only: don't include fallback code inside the baked provider

      --deduplication <DEDUPLICATION>
          configures the deduplication of locales for exported data payloads. If not set, determined by the export format: if --format=baked, a more aggressive deduplication strategy is used.
          
          [possible values: maximal, retain-base-languages, none]

      --segmenter-models [<SEGMENTER_MODELS>...]
          Include these segmenter models in the output. Accepts multiple arguments. Defaults to 'recommended' for the recommended set of models. Use 'none' for no models
          
          [default: recommended]

      --input-blob <INPUT_BLOB>
          Use data from this blob file instead of generating it from sources

  -h, --help
          Print help

  -V, --version
          Print version
